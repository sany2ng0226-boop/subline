# Windows 候选版：范围与验收

状态：首版范围已确认，候选实现与构建入口已加入源码；版本 `0.2.0-beta.3-windows.1`。尚未公开发布，也未完成朋友电脑的真实音源与 GPU 验收。Windows 构建结果与实机结果必须分别记录，不能从 Mac beta.2 的验收推导 Windows 可用。

## Problem / User / Context

朋友需要在 Windows 电脑上为视频、网课等电脑声音，以及现场麦克风声音生成实时双语字幕。已知有 NVIDIA 独显，具体显卡、显存、内存和驱动未知。目标为 Windows 10/11 x64，不承诺未经验证的最低配置或实时速度。

## Solution

沿用 Subline 产品名、连续字幕界面、共享识别与翻译规则，扩展现有 Electron 桌面宿主。

- 录音前选择“系统音频”或“麦克风”，同一时间使用一种输入。系统音频读取默认播放设备的声音，不是某个指定应用的独立音轨；切换音源需先停止录音。
- 默认本地 SenseVoice 识别与 Hy-MT2 7B Q4_K_M 翻译，首次下载模型前确认。所需模型下载完成后不需要 API Key、LM Studio 或另启模型服务器。
- 翻译尝试 NVIDIA CUDA，检查实际可用内存及显存；CUDA 不可用或未分配 GPU 层时显示 CPU 状态与原因。资源不足则明确报错，不自动启用云服务。
- 沿用手动归档、单层文件夹、改名和移动。停止录音不自动保存；保存前等待需要的译文完成。归档只存已定稿文字和已完成译文，不存原始音频。

## Constraints

- 安装器和 ZIP 面向 x64，当前安装器未签名。SmartScreen 可能显示未知发布者；核对下载来源和 SHA-256，不要求全局关闭系统防护。
- 设置、模型与归档独立保存在 `%APPDATA%\Subline Windows Candidate`，不读取、迁移或覆盖 Mac 数据。常规卸载保留该目录；备份归档时应退出应用后复制完整目录，且不要公开分享其中的设置或凭据。
- 默认本地处理；已有的可选 API 设置仅在用户明确配置并选择后使用。音频不上传，切换到 API 翻译会把待翻译文字及有限原文上下文发往所选端点。
- 系统声音采集依赖 Windows、默认播放设备及 Electron 的回环能力。实现不保存屏幕画面，采集得到的临时视频轨立即停止；真实音源与受保护内容的行为仍需实机核验。
- 现有 Mac beta.2 分发及其设置、归档不因本候选改动而替换。

## Non-goals

不合并 Meeting、面试辅助或影子跟读；不做双人设备同步、麦克风与系统声音混音、跨设备归档同步、自动云端降级或自动更新已安装的 Mac 应用。首版不提供 Windows ARM64 安装包。

## Success Criteria：朋友实机清单

构建成功、原生依赖可加载、合成界面检查通过，只说明候选包达到相应自动检查边界。以下项目在真实电脑上完成后才可称为该配置可用：

- [ ] 记录 Windows 版本、显卡型号、显存、内存和 NVIDIA 驱动版本；安装并正常启动候选。
- [ ] 确认应用内模型下载成功。选择麦克风，真人说一段明确语言的话，看到原文与译文；停止后收音释放。
- [ ] 停止录音后切换系统音频，播放一段已知内容，看到对应原文与译文；确认没有把麦克风说话混入系统输入。
- [ ] 记录实际翻译后端；在可用 NVIDIA 环境验证 CUDA 模型装载及实际翻译。只有显示卡存在或 CUDA 依赖能加载不足以证明 GPU 推理通过。
- [ ] 在可控的 CUDA 不可用环境验证 CPU 降级提示和实际本地翻译；资源不足时显示明确错误，且没有自动发往云服务。
- [ ] 等待译文完成后手动归档，改名或移入文件夹；关闭并重启，确认记录、文件夹和设置能读回。
- [ ] 记录卡顿、译文失败、音源异常和连续使用时长；性能结论限定在这台电脑和此次使用条件。

## Risks / Open Questions

显卡和内存容量、驱动兼容性、真实系统回环、真人收音、模型下载网络和长时间性能均待验证。CPU 降级不保证满足实时使用。Windows 候选尚未取得代码签名；安装器的 Windows 信任状态不能沿用 Mac 的签名、公证结论。

## Worth-it Decision

已确认推进朋友可试用候选：复用现有 UI、模型和桌面宿主，只补 Windows 音频、推理后端和打包能力。先以朋友实机结果判断兼容性和后续投入，不另建功能不同的 Windows 产品。
