# 使用流程与产品规则

本文描述 Realtime Translator 共享界面在 macOS、iOS 和 Web 上的已实现行为。各端能力与隐私边界见[产品全貌与平台能力](overview.md)。

## 首次启动与母语

首次启动会进入引导页。系统根据设备偏好语言预选中文、日语、英语或韩语；无法匹配时使用英语。用户可在引导中同时确认母语、字号和主题。

“母语”同时决定：

- 应用界面语言；
- 常规翻译的目标语言；
- 中文作为目标语言时的输出字形，统一归一化为简体中文。

macOS 没有现有设置时默认启用本地 Hy-MT2 7B 翻译；已有设置保留原来的翻译方式。此默认不改变 SenseVoice 或规则切句，也不自动开始下载。

完成引导后进入主页。如果当前 ASR 模型已下载，应用会在不申请麦克风权限的前提下后台预热识别引擎。

## 开始一次转写

1. 用户在主页点击录音按钮。主页没有独立的翻译开关；是否翻译由设置中的“翻译方式”决定。
2. 应用检查当前识别模型，以及已启用的本地翻译模型是否就绪。如果缺失，先展示模型名称与体积请求确认。
3. 确认后下载转入后台，主页显示本次录音正在等待的模型进度。可取消“本次录音”的等待，模型仍继续后台下载；所需任务全部成功后，应用自动开始录音。
4. 录音前先显示应用内权限说明，随后才请求系统权限。已拒绝麦克风时，原生端可引导打开对应系统设置；浏览器无法代用户打开站点或系统权限页。
5. macOS 选择系统音频时，首次使用也会先显示说明。由于系统不提供可预查的权限状态，权限拒绝只能在采集失败后识别，再引导到“屏幕与系统音频录制”设置。

macOS 主页录音按钮旁显示无文字的音量条，随实际送入识别器的音频强弱起伏。静音、停止录音或未收到新音频时自然回落；音量条不显示提示文字、悬停说明或弹窗。它仅反映输入信号强弱，不代表识别准确度、语音活动或采集健康状态；未提供音量事件的其他平台不显示该条。

录音中，说话时的部分识别结果实时更新；停顿、切段或连续说话过长时，当前内容落为带本地时钟的定稿行。定稿时会优先保留实时识别中较完整、且未被后续稳定结果否定的内容，避免确认时因单次识别波动而无故缩短；已经与后续稳定结果冲突的早期内容不会被带入定稿。iOS 在候选切换时会将文本及其识别语种作为同一结果确定。

macOS 会先合并同语言且音频相邻的已识别片段，再显示为定稿行；识别器及其音频窗口保持不变。合句期间，文字仍在同一字幕行实时续写和修正。系统使用规则判断切句，不调用模型判断句子是否结束。句子结束且内容足够长时定稿；日语以明确谓语（如「です」「ます」）结束、至少 4 字且音频至少 1 秒的短句也可提前定稿。累计音频达到 14 秒或文本达到 180 字时定稿；没有新语音活动时等待 1.4 秒，持续语音活动可延后这次等待，但首个待合并片段最多等待 12 秒。识别语言改变或片段音频间隔超过 1.5 秒时另起一行。停止录音会提交剩余已识别文字，新会话不沿用待合并内容。iOS 与 Web 不使用这一合句步骤。

三端主页使用按时间正序排列的连续字幕流，旧句在上、新句在下。当前句从首次部分识别起就在同一位置续写和修正；定稿时更新原行的文字与时间，译文随后在该行下方回填，不再将文字从临时区搬到定稿框或历史区。没有部分识别事件的定稿也直接加入该字幕流。所有句子的原文使用相同字号与样式，左对齐，原文字号比设置字号大 7 像素，译文比设置字号大 5 像素；以 15 像素的设置字号为例，原文为 22 像素、译文为 20 像素。两者均为常规字重、1.6 倍行高。没有独立的大字框、固定高度文本框或句子切换动画。

字幕按语言指定字体：日语优先使用 macOS 原生 Hiragino Sans，简体中文优先使用 PingFang SC，并提供其他平台的字体回退。定稿原文优先使用识别段的语种，临时原文使用所选识别语言；译文当前使用母语设置标注语言。因此固定日语识别、中文母语的课堂场景会分别使用日文字形与简体中文字形；自动识别的临时句与反向翻译场景仍有语言标注边界，不能保证它们都使用正确的专用字形。

正文列居中，最大宽度约为 36 个原文字号的全角字宽；时间戳放在左侧独立的 52 像素列，与正文相隔 12 像素。窄屏下时间戳列缩为 40 像素、间隔缩为 8 像素。每组双语间距为 22 像素，原文与下方译文间距为 6 像素，译文使用适配浅色和深色主题的低饱和蓝。原文和译文自然换行，并启用严格的行首行尾标点处理；确认前后不改变该行的字号或字重。

三端当前句默认暂缓显示尚未稳定尾部的最后 2 个 Unicode 码点，与当前全文匹配的稳定前缀完整显示；后续识别仍可修正已显示内容，定稿时完整显示原文，此处理仅影响显示，不改写识别结果、翻译或归档。

当前句已确认的显示前缀使用较深颜色，尚未稳定的尾部使用稍浅颜色。已确认前缀只是识别器当前的稳定判断，不代表文字永久不变；后续识别修正或音频窗口重基仍可能调整它。macOS 将待合句片段与识别器提供的稳定前缀一并展示；提供的前缀与当前全文不匹配时，整段部分识别结果使用浅色，避免误标稳定内容。iOS 与 Web 尚未提供这一元数据，保留整段原文原有的深色外观，不据此声明其稳定性。

正在字幕流末尾阅读时，原文续写、定稿和译文回填后自动跟随底部；向上滚动查看前文时，新内容不强制拉回。整条字幕流共同滚动，原文和译文不再各自内部滚动。这些显示处理不改变识别刷新频率、切句规则或翻译请求。

只有定稿行会发起翻译、进入归档或参与清屏判定；瞬时的部分识别结果不会被保存。停止录音仍由宿主管线提交剩余文字后清除临时行；清屏也会清除临时行。长句被主动切段后，下一行会继续覆盖后续语音并保持时间连续，不会因切段漏掉开头。

## 翻译规则

翻译方式有三种：无、本地模型、API 服务（本机 / 云端）。选择“无”即关闭翻译；选择本地模型或 API 服务即开启翻译。

每个定稿段分别请求翻译，译文通过行 ID 异步回填，因此转写不需等待上一行译文。macOS 使用应用内 Hy-MT2 7B 或 OpenAI 兼容 API 时，会附带当前语言对最近两段原文，每段最多 400 字符，作为理解当前段的上下文；请求只要求输出当前段的译文，不将生成的译文作为后续上下文。新会话、翻译配置变化或语言对切换时清空上下文。iOS 与 Web 的 API 请求不附带会话原文上下文。同一语言无需翻译时不显示译文占位；单行翻译失败仅在该行显示失败，不中断识别或其他行。

macOS 的应用内 Hy-MT2 7B，以及本机回环 API 端点的 Hy-MT2 7B 翻译采用流式回填：首批非空译文返回后即在对应原文下方显示，后续在原位续写。部分译文仍处于翻译中，只有请求完整成功后才视为完成；流中断或生成未完整结束时，清除半截译文并显示该行失败。部分回填不释放翻译队列的执行名额。应用内 Hy-MT2 与 API 路径共用翻译提示词和显式原文上下文，每句不继承生成的对话历史；本地生成温度为 0，单句最多 1024 个 token、30 秒超时，超时、空译文或达到上限而未完整结束时按失败处理。其他 API 模型、远程端点以及 iOS、Web 保留完整结果回填。

macOS 的翻译在后台队列中执行，同一时间最多处理一个请求，最多保留三个尚未开始的请求。等待超过 15 秒的请求不再启动；队列已满时，新句替换最早的等待请求。被跳过的句子保留原文，译文区结束等待并显示失败标记，悬停可查看积压或等待超时原因。这个限制只管理翻译，不暂停音频采集、部分识别或定稿。修改翻译配置会取消旧配置下尚未开始的翻译；正在执行的请求由旧翻译进程退出后结束，新配置的请求随后按队列执行。

### 指定识别语言

识别语言被锁定为中、日、英、韩某一种时，非母语定稿段翻成母语。母语段被视为无需翻译，不做反向翻译。

### 自动识别与反向翻译

识别语言为 `auto` 时，翻译目标随本次录音会话调整：

- 识别到非母语时，将该段翻成母语，并记住这一外语；
- 之后识别到母语时，将该段反向翻成最近一次记住的外语；
- 每次新录音会话都清空外语历史，因此会话第一句如果是母语，当时没有反向目标，不显示译文。

系统会依据日文假名和韩文字母修正明显的自动语种误判，但纯汉字文本无法靠字形确定是中文还是日文。短句或语种误判影响结果时，将识别语言锁定为已知语言可避免 `auto` 的语种决策。

## 设置

设置分为四组，修改后自动保存：

- **通用**：母语、主页字号、浅色/深色/跟随系统主题。
- **语音识别**：自动或固定识别语言，以及该平台和语言支持的识别模型。变更语言或模型后，下次录音使用新配置。
- **翻译**：无/本地模型/API 服务（本机 / 云端）三态方式；有多个本地模型时可选模型；API 服务可配置 Base URL、模型名和 API Key，并可发起一次最小真实请求测试连通性。Base URL 必须是能接受 `/chat/completions` 的 OpenAI 兼容端点根路径。

- **模型管理**：查看可用的识别/翻译模型、近似或已占用空间、是否已下载以及是否在用，并执行下载、取消、重试或删除。iOS 只列出 ASR 模型，Apple Translation 语言包由系统管理。

macOS 用户可在“本地模型”中选择 Hy-MT2 7B，通过应用下载后直接运行；无需安装 LM Studio、配置端口或填 API Key。

“使用本机 Hy-MT2”是应用内本地 7B 的快捷选择，会启用本地翻译并选择 Hy-MT2 7B，不配置 API 端口或启动外部服务。用户仍可手动选择 API 服务并填写 LM Studio 等已有服务的地址、模型标识和可选凭据。

macOS 在主页额外显示麦克风/系统音频切换，录音或启停进行中不能切换。

## 模型下载与删除

- 选择未下载的识别或本地翻译模型时，应用会就地询问是否下载。取消确认不会回退已保存的选择，可以在稍后录音时再下载。
- 确认后下载由应用级管理器在后台执行，多个模型可并行下载。离开设置页不会中止任务。
- 在模型管理中取消某个下载，会中止该模型的传输并删除其残留文件，让它回到未下载状态；不影响其他正在下载的模型。
- 模型共用的 Silero VAD 不在选择列表中。并行下载识别模型时公共文件只获取一次，删除单个识别模型也保留 VAD。Web 的 VAD 随应用外壳提供，不从外部模型源下载；首次安装 ASR 模型时仍会从同源资源写入模型缓存，并计入就绪检查与下载进度。
- 当前续传单位是完整文件：重新触发会跳过已下载的完整文件，但半个文件会从头下载；重启应用后不会自动续传，需要用户再次触发。
- macOS 的 Hy-MT2 7B 权重约 4.62 GB（界面按二进制单位显示约 4.3 GB），来自 Tencent 官方 GGUF Q4_K_M 的固定 revision；下载完成后检查文件大小与 SHA-256，不匹配的文件不视为就绪。模型权重不包含在安装包中。下载进度、取消与重试沿用上述流程。
- 下载器依照模型注册表中的有序源逐个尝试。macOS 和 iOS 的多数模型优先使用项目自托管源并以上游源兜底；macOS 专用 M2M-100 1.2B 只有自托管源。Web 受 CORS 限制，使用可从浏览器访问的上游或镜像源。

## 清屏与归档

主页在存在已定稿行时提供两种处理：

- **删除**：只清空当前主页的转写内容。
- **归档**：先以当前日期时间为默认名称，也可由用户编辑；同名时在默认名后增加序号。保存完成后清空主页。

归档只包含定稿行的本地时间、原文和当时已完整成功回填的译文；正在流式生成的部分译文不保存。尚未回填的译文不会在之后自动追加到已保存快照。归档列表按创建时间倒序显示，可查看完整内容或删除单条归档。

## 错误与降级

- 麦克风或系统音频权限拒绝、音频采集失败、音频中断、ASR 初始化失败和识别进程崩溃会结束当前录音，主页显示可本地化的错误提示。已定稿的行仍保留在主页。
- 单行翻译请求失败只结束该行的等待动画并显示失败标记，不停止转写。macOS 翻译子进程异常退出，或 Web 显式预热本地模型失败，会额外显示引擎级警告并结束所有未完成译文的等待动画。Web 在行翻译期间的模型装载或 Worker 运行失败，以及 iOS Apple Translation 不可用，则表现为行级失败，不额外显示引擎级警告。
- iOS 本地翻译在 iOS 18 以下、不支持的语言对或语言包缺失时不会自动把文本发往云端；该行会失败，需由用户明确改选云端翻译。
- API 翻译需要 Base URL 和模型名；远程端点还需要 API Key。`127.0.0.1`、`localhost` 和 `[::1]` 回环端点允许不填 API Key，并禁止请求重定向。空译文视为失败。请求失败或超时时只影响对应行；应用不会在云端与本地翻译之间自动切换。
- 固定识别语言可规避 `auto` 对短段的部分语种误判；将某个语种专用模型删除后，下次使用它录音时会再次请求下载，不会静默改用其他已下载模型。
