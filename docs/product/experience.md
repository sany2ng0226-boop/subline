# 使用流程与产品规则

本文描述 Subline 共享界面在 macOS、iOS 和 Web 上的当前源码行为。本轮单页设置与统一模型选择器先落 Dev 分支，尚未发布。各端能力与隐私边界见[产品全貌与平台能力](overview.md)。

## 首次启动与基础设置

macOS 稳定渠道的朋友测试版安装时将 Classroom Translator 拖入“应用程序”后正常打开；应用已签名并公证，无需移除隔离属性或关闭系统安全性。macOS 仍可能显示正常的首次打开确认，后续采集音频仍须授予对应权限。

首次启动会进入引导页。系统根据设备偏好语言预选中文、日语、英语或韩语；无法匹配时使用英语。第一步供用户确认界面语言、字号和主题。

第二步标题为“欢迎使用 Subline”，副标题为“选择要使用的模型，之后可以在设置里更改。”，只提供两个选择：

- **识别模型**：列出当前平台的识别模型注册表选项，每项显示模型名称和近似体积；
- **翻译模型**：默认选择“不翻译”，支持本地翻译的平台同时列出可用翻译模型及近似体积。Hy-MT2 7B 显示“超高质量”徽章；不支持本地翻译的平台只显示“不翻译”。

引导中选择的界面语言（设置字段仍名为 `nativeLang`）同时用于初始化首次翻译目标。完成引导后，“翻译成”独立保存在 `translation.targetLang`；例如中文界面可以翻成日语，之后更改界面语言不会覆盖已选目标。目标为中文时，输出字形统一归一化为简体中文。缺少有效目标的旧设置继承其原 `nativeLang`，保留此前的译文语言。

点击“开始使用”时，应用保存所选识别模型，并按该模型支持范围保留或调整识别语言；选择“不翻译”会关闭翻译，选择翻译模型会开启翻译并保存该模型。首次翻译目标初始化为第一步选择的界面语言，不在模型选择步骤另设目标语言，之后可在设置首页独立更改。

“开始使用”只会为尚未就绪的所选识别模型启动后台下载；已就绪时不重复下载。选择翻译模型不会在此时下载它，之后开始录音时仍按既有模型就绪检查和确认流程处理。

完成引导后进入主页。如果当前 ASR 模型已下载，应用会在不申请麦克风权限的前提下后台预热识别引擎。

## 开始一次转写

1. 用户在主页点击录音按钮。主页没有独立的翻译开关；是否翻译由设置中的“翻译模型”决定，选择“不翻译”即关闭。
2. 应用检查当前识别模型，以及已启用的本地翻译模型是否就绪。如果缺失，先展示模型名称与体积请求确认。
3. 确认后下载转入后台，主页显示本次录音正在等待的模型进度。可取消“本次录音”的等待，模型仍继续后台下载；所需任务全部成功后，应用自动开始录音。
4. 录音前先显示应用内权限说明，随后才请求系统权限。已拒绝麦克风时，原生端可引导打开对应系统设置；浏览器无法代用户打开站点或系统权限页。
5. macOS 选择系统音频时，首次使用也会先显示说明。由于系统不提供可预查的权限状态，权限拒绝只能在采集失败后识别，再引导到“屏幕与系统音频录制”设置。

录音实际开始后，Electron 桌面端会阻止显示器自动休眠，录音停止、识别进程异常结束、窗口关闭或应用退出时解除。Web 会在页面可见且浏览器支持 Screen Wake Lock 时请求保持屏幕唤醒；录音期间页面重新可见后会再次请求，停止录音时释放。浏览器不支持时跳过；申请或释放失败只在开发者控制台记录警告，不影响录音。

主页顶栏只放操作图标（清屏、归档、设置，支持系统音频时另有音源切换）、音量波形、Internal 的主要语言选择和录音按钮，不显示应用标题、行数、时钟或状态标语；模型加载与翻译引擎错误以顶栏内联提示出现。窄屏时操作收进“…”菜单，录音改用底部圆形按钮，不显示音量波形。

macOS 主页录音按钮前显示无文字的音量波形：一排柱形从右向左连续滚动，最右为当前输入强弱。静音、停止录音或未收到新音频时自然回落；音量波形不显示提示文字、悬停说明或弹窗。它仅反映输入信号强弱，不代表识别准确度、语音活动或采集健康状态；未提供音量事件的其他平台不显示。

录音中，说话时的部分识别结果实时更新；停顿、切段或连续说话过长时，当前内容落为带本地时钟的定稿行。定稿时会优先保留实时识别中较完整、且未被后续稳定结果否定的内容，避免确认时因单次识别波动而无故缩短；已经与后续稳定结果冲突的早期内容不会被带入定稿。iOS 在候选切换时会将文本及其识别语种作为同一结果确定。

macOS 会先合并同语言且音频相邻的已识别片段，再显示为定稿行；识别器及其音频窗口保持不变。合句期间，文字仍在同一字幕行实时续写和修正。系统使用规则判断切句，不调用模型判断句子是否结束。句子结束且内容足够长时定稿；日语以明确谓语（如「です」「ます」）结束、至少 4 字且音频至少 1 秒的短句也可提前定稿。累计音频达到 14 秒或文本达到 180 字时定稿；没有新语音活动时等待 1.4 秒，持续语音活动可延后这次等待，但首个待合并片段最多等待 12 秒。识别语言改变或片段音频间隔超过 1.5 秒时另起一行。停止录音会提交剩余已识别文字，新会话不沿用待合并内容。iOS 与 Web 不使用这一合句步骤。

三端主页使用按时间正序排列的连续字幕流，旧句在上、新句在下。当前句从首次部分识别起就在同一位置续写和修正；定稿时更新原行的文字与时间，译文随后在该行下方回填，不再将文字从临时区搬到定稿框或历史区。没有部分识别事件的定稿也直接加入该字幕流。每行左侧的窄列以 `HH:MM:SS` 显示本地时钟：当前句先显示首次收到部分识别的时刻，定稿后按本次录音开始时刻与片段起点换算成实际时间。时钟使用等宽数字和浅色、深色主题中均达到 WCAG AA 的弱化文字色，并随主页字号设置调整。所有句子的原文使用相同字号，左对齐，原文字号比设置字号大 7 像素，译文比设置字号大 4 像素；以 15 像素的设置字号为例，原文为 22 像素、译文为 19 像素。两者均为常规字重，原文 1.55 倍、译文 1.6 倍行高。正在说的当前句与最近一条定稿行为视觉焦点，使用主墨色；更早的行原文与译文退为次级颜色，只换颜色、不做动画。当前句末尾显示闪烁光标（减少动态效果时不闪烁）。新行和新译文只做透明度淡入，没有位移、模糊或光晕；系统要求减少动态效果时不做过渡。没有独立的大字框或固定高度文本框。

字幕按语言指定字体：日语优先使用 macOS 原生 Hiragino Sans，简体中文优先使用 PingFang SC，并提供其他平台的字体回退。定稿原文优先使用识别段的语种，临时原文使用所选识别语言；译文使用独立的翻译目标设置标注语言。因此固定日语识别、翻译成中文的场景会分别使用日文字形与简体中文字形，不受界面语言影响；自动识别的临时句尚不能标注具体语种。

正文列居中，最大宽度约为 36 个原文字号的全角字宽。每组双语间距为 26 像素，窄屏下为 22 像素；原文与下方译文间距为 6 像素，译文向右缩进并带左侧强调色竖线，文字使用适配浅色和深色主题的蓝色。原文和译文自然换行，并启用严格的行首行尾标点处理；确认前后不改变该行的字号或字重。

三端当前句默认暂缓显示尚未稳定尾部的最后 2 个 Unicode 码点，与当前全文匹配的稳定前缀完整显示；后续识别仍可修正已显示内容，定稿时完整显示原文，此处理仅影响显示，不改写识别结果、翻译或归档。

当前句已确认的显示前缀使用较深颜色，尚未稳定的尾部使用稍浅颜色。已确认前缀只是识别器当前的稳定判断，不代表文字永久不变；后续识别修正或音频窗口重基仍可能调整它。macOS 将待合句片段与识别器提供的稳定前缀一并展示；提供的前缀与当前全文不匹配时，整段部分识别结果使用浅色，避免误标稳定内容。iOS 与 Web 尚未提供这一元数据，保留整段原文原有的深色外观，不据此声明其稳定性。

字幕流默认跟随底部：原文续写、定稿、译文回填（包括译文换行后才撑高的行）和窗口缩放后都贴回最新内容。只有用户主动向上滚动并离开底部 40 像素以上才停止跟随，此后新内容不强制拉回，并在底部出现“回到最新”按钮；用户滚回底部 40 像素以内即恢复跟随。点击“回到最新”平滑滚到底部，途中到达的新内容会被一并跟上；途中用户再次向上滚动则保持用户位置。整条字幕流共同滚动，原文和译文不再各自内部滚动。这些显示处理不改变识别刷新频率、切句规则或翻译请求。

只有定稿行会发起翻译、进入归档或参与清屏判定；瞬时的部分识别结果不会被保存。停止录音仍由宿主管线提交剩余文字后清除临时行；清屏也会清除临时行。长句被主动切段后，下一行会继续覆盖后续语音并保持时间连续，不会因切段漏掉开头。

## 翻译规则

“翻译模型”在同一个选择器中提供“不翻译”、本平台本地模型或系统翻译，以及“API 服务（本机 / 云端）”。选择“不翻译”即关闭翻译；选择其他项即开启翻译。

每个定稿段分别请求翻译，译文通过行 ID 异步回填，因此转写不需等待上一行译文。应用内 Hy-MT2 7B 每次只翻译当前段原文，每句使用新的独立会话，不附带此前原文或生成的对话历史，避免将参考上下文一起翻出。macOS 的 OpenAI 兼容 API 路径仍附带当前语言对最近两段原文，每段最多 400 字符；请求只要求输出当前段译文，不将生成的译文作为后续上下文，新会话、翻译配置变化或语言对切换时清空该上下文。iOS 与 Web 的 API 请求不附带会话原文上下文。同一语言无需翻译时不显示译文占位；单行翻译失败仅在该行显示失败，不中断识别或其他行。

macOS 的应用内 Hy-MT2 7B，以及本机回环 API 端点的 Hy-MT2 7B 翻译采用流式回填：首批非空译文返回后即在对应原文下方显示，后续在原位续写。部分译文仍处于翻译中，只有请求完整成功后才视为完成；流中断或生成未完整结束时，清除半截译文并显示该行失败。部分回填不释放翻译队列的执行名额。应用内 Hy-MT2 使用共享提示词的当前句模式，API 路径保留其显式原文上下文模式，两者都不继承生成的对话历史；本地生成温度为 0，单句最多 1024 个 token、30 秒超时，超时、空译文或达到上限而未完整结束时按失败处理。其他 API 模型、远程端点以及 iOS、Web 保留完整结果回填。

macOS 的翻译在后台队列中执行，同一时间最多处理一个请求，最多保留三个尚未开始的请求。等待超过 15 秒的请求不再启动；队列已满时，新句替换最早的等待请求。被跳过的句子保留原文，译文区结束等待并显示失败标记，悬停可查看积压或等待超时原因。这个限制只管理翻译，不暂停音频采集、部分识别或定稿。修改翻译配置会取消旧配置下尚未开始的翻译；正在执行的请求由旧翻译进程退出后结束，新配置的请求随后按队列执行。

### 翻译目标与识别语言

自动检测或固定识别语言均翻成“翻译成”指定的语言，不随会话最近听到的外语改变。例如中文界面、日语目标时，中文和英语段都翻成日语，日语段不会反向翻成其他语言。同语言通常无需翻译，中文仍可做必要的简体字形归一化。

共享核心只为未传 `targetLang` 的旧调用保留母语与会话反向翻译规则；当前三端宿主明确传入独立目标，不使用该兼容策略。

系统会依据日文假名和韩文字母修正明显的自动语种误判，但纯汉字文本无法靠字形确定是中文还是日文。短句或语种误判影响结果时，将识别语言锁定为已知语言可避免 `auto` 的语种决策。

## 设置

macOS 的 Subline 与 Subline Internal 使用各自的设置、归档和模型缓存；未打包的开发预览以 Subline Preview 为名并使用指定的独立数据目录。首次启动任一新渠道都按新安装处理；在内部版修改识别或翻译设置、下载模型、保存或删除归档，不会同步到稳定渠道。窗口标题显示当前渠道应用名，便于辨认。

Internal 主页在录音按钮前提供“主要语言”选择，选项只显示“自动检测”或语言名（英语、日语、韩语、中文），不带“主要语言”前缀，读屏标签仍为“主要语言”；稳定渠道不显示此快捷入口。选择直接保存识别语言，与设置页同步并在重启后保留，不弹确认窗；录音、启停或保存进行中不可修改。当前识别模型支持新语言时保留模型，否则切回默认 SenseVoice；此操作不改变 Hy-MT2 7B 或切句规则。

设置为一个可滚动页面，修改后自动保存，常用配置无需切换标签页：

- 顶部直接显示**识别语言**（自动或固定语种）和**翻译成**（独立目标语言）。
- **识别模型**列出当前平台与识别语言支持的模型；**翻译模型**在同一选择器内列出“不翻译”、本地模型／系统翻译和 API 服务。两个模型选择器都在各选项内统一提供选择标记、体积、下载状态、进度、下载／取消／重试／删除操作，不另设模型管理入口。Hy-MT2 7B 保留“超高质量”徽章。
- 选择 API 服务后才显示 Base URL、模型名和 API Key；支持连接测试的平台可发起一次最小真实请求。Base URL 必须是能接受 `/chat/completions` 的 OpenAI 兼容端点根路径。
- **外观与辅助**默认折叠，展开后可改界面语言、主页字号、浅色／深色／跟随系统主题及字幕读屏播报；宿主支持时也提供窗口置顶。界面语言与翻译目标分别保存。

macOS 用户下载 Hy-MT2 7B 后可直接在“翻译模型”中选用，无需安装 LM Studio、配置端口或填 API Key。已有 LM Studio 等服务可通过 API 服务填写地址、模型标识和可选凭据。

macOS 在主页额外显示麦克风/系统音频切换，录音或启停进行中不能切换。

## 模型下载与删除

- 设置页仅允许选中已下载的本地识别／翻译模型；未下载、下载中或状态不可用的模型不能直接切换为当前模型。“不翻译”、API 服务和平台支持的系统翻译不受本地模型缓存门槛限制。此限制仅针对设置选择器；首次引导仍按上文流程选择模型、下载识别模型，录音前仍检查所需模型是否就绪。
- 点击模型选项旁的下载或重试操作，确认模型体积后由应用级管理器后台下载，多个模型可并行下载。下载完成不会自动选用，用户需再选择该模型。离开设置页不会中止任务。
- 取消确认或取消下载均不更改当前模型。取消下载会中止该模型传输并删除残留文件，使其回到未下载状态，不影响其他下载。已下载模型可在同一选项内确认删除；录音、启停或模型加载中禁止删除。
- 模型状态查询或下载／删除操作失败时，选择器就地显示错误并提供重试。iOS 不列出本地翻译权重，Apple Translation 语言包仍由系统管理。
- 模型共用的 Silero VAD 不在选择列表中。并行下载识别模型时公共文件只获取一次，删除单个识别模型也保留 VAD。Web 的 VAD 随应用外壳提供，不从外部模型源下载；首次安装 ASR 模型时仍会从同源资源写入模型缓存，并计入就绪检查与下载进度。
- 当前续传单位是完整文件：重新触发会跳过已下载的完整文件，但半个文件会从头下载；重启应用后不会自动续传，需要用户再次触发。
- macOS 的 Hy-MT2 7B 权重为 4,624,648,896 字节（界面按二进制单位显示约 4.3 GB），来自 Tencent 官方 GGUF Q4_K_M 的固定 revision。该文件已登记精确字节数和 SHA-256，只有两项校验都通过才会安装；今后加入但尚未登记 pin 的模型文件仍可下载。模型权重不包含在安装包中。下载进度、取消与重试沿用上述流程。
- 下载器依照模型注册表中的有序源逐个尝试。当前启用的原生端来源仍是上游：ASR 与 M2M-100 418M 使用锁定提交的 Hugging Face 文件，Silero VAD 使用 sherpa-onnx 官方发布资产，M2M-100 1.2B 使用原上游发布资产；Subline 的 `models-v1` 自托管源仅为尚未启用的未来选项。Web 受 CORS 和缓存键约束，继续使用可从浏览器访问的 Hugging Face 主分支或镜像源。
- 原生端文件登记了 pin 时，macOS 与 iOS 会在安装前核对精确字节数和 SHA-256；内容不符时丢弃本次结果并尝试下一个来源，所有来源均失败才报告下载失败。没有 pin 的文件跳过这两项核对，保持可下载。

## 清屏与归档

主页在存在已定稿行时提供两种处理；本轮 Dev 分支也允许对仅有系统原音、没有字幕的会话操作：

- **删除**：清空当前主页的转写内容，底部出现“已删除字幕 · 撤销”条。撤销会原样恢复这些行，删除期间才到达的译文也会回填；撤销机会保留到用户关闭该条、开始新一次录音或归档清屏为止。
- **归档**：打开保存弹窗，用户确认名称后手动保存。保存成功后才清空主页；失败时保留当前内容并显示错误。停止录音不会自动归档。

停止录音后主页仍有定稿行（Dev 分支还包括未归档原音）时，顶栏常驻“未保存 · 归档”提示，点击直接打开保存弹窗；录音中不显示。正在录音或有未归档内容时，macOS / Windows 关闭窗口或退出应用前会弹出确认，默认按钮为“先不关闭”；Web 离开页面时显示浏览器自带的离开提示。iOS 无此保护。

归档的文字部分包含定稿行的本地时间、原文和当时已完整成功回填的译文；正在流式生成的部分译文不保存。尚未回填的译文不会在之后自动追加到已保存快照。归档列表按创建时间倒序显示，可查看完整内容。归档详情沿用主页的窄时间列和带左侧强调线的译文排版；旧归档没有行时间时直接省略时间，不显示空白占位列。

### Dev 归档并退出

Subline Dev 选择“归档并退出”时，先收停录音、恢复仍可撤销的删除并合入待恢复草稿；有定稿内容或系统原音时打开系统原生保存窗口，由用户确认 `.txt` 文件名与磁盘文件夹。确认保存位置后才取得最新字幕快照，包含选择窗口打开期间新到达的定稿和完整译文。文本包含各定稿行的时间（如有）、完整原文及当时已完成的译文，不包含尚未完整回填的译文。应用先原子写入所选文本文件，再以该文件名在 Dev 内保存包含原音附件的归档；两处保存均成功后才清空会话并退出。仅有原音时，文本文件没有字幕正文，原音仍保存在应用归档中。

取消保存或任一步写入失败时，窗口与字幕保留。若文本已写入而应用内归档失败，磁盘上的文本文件可能已存在，但应用不会据此确认退出。Dev 不对人工选择保存位置设置 30 秒倒计时。其他渠道沿用原有归档退出路径，公开版的保存方式未由本项更改。

以上为 Dev 分支改动，未发布、未安装；系统原生保存窗口尚未实机验收。

### 归档原音回听（先落 Dev 分支）

系统原音随归档保存与回听属于普通 Subline 的产品能力，本轮先在 Dev 分支接入，尚未发布或安装。仅保存系统音频，不保存麦克风原音；保存的是送入识别管线的 16 kHz 单声道 PCM16 WAV，约占 115 MB／小时，不是原始播放源的无损副本。当前会话有原音时显示“系统原音会随归档保存，可在归档中回听。”

原音保存不依赖是否识别出文字；没有字幕也可归档、保留恢复草稿，并在下次启动时恢复。多次开始／停止的系统录音按段与同一归档绑定。删除当前会话时，字幕与原音一起进入撤销；撤销一起恢复，确认丢弃时清理未归档原音。删除归档后清理不再由其他归档引用的音频，丢弃草稿不删除已有归档仍引用的原音。

停止录音先等待 AudioWorklet 交付最后未满块的样本并确认，再等识别定稿确认及 WAV 文件头更新、写入同步完成，才报告停止成功。原音写入失败会提示停止后重试；关闭前归档若取消原生保存窗口或任一步写入失败，保留窗口与会话，不以部分成功确认退出。

带有原音附件的归档，在普通归档详情和文件夹归档详情中按段显示“原音”、开始时间、时长及原生音频控件。用户可手动播放、暂停或拖动进度；进入详情不自动播放，也不预加载音频内容。播放器只通过本机宿主取址，读取端核对归档与录音附件 ID，不能用任意磁盘路径读取。失败显示错误并提供重试；旧归档未保存原音时明确说明，不根据文字补造录音。

本轮已完成离线回归与 Electron 隐藏窗口的合成跨进程验证，覆盖音频尾块、纯原音归档、退出进程后重开、解码、静音播放和进度拖动。该验证使用隔离的临时数据与合成音频，不代表真实系统回环采音、真实识别／翻译或长时间连续录音已重新验收。

### Internal 文件夹管理

仅 macOS Internal 提供单层文件夹管理，不绑定课程。归档页可新建、重命名文件夹，并在“全部记录”“未分类”和各文件夹之间筛选；记录可手动改名，或移动到其他文件夹及“未分类”。删除记录前需要确认。原有记录保留原名与内容，没有文件夹归属的记录显示在“未分类”。

保存弹窗预填内容标题和上次成功保存时使用的文件夹，用户仍可修改后再保存。标题在本机从已有文字中提取，逐行优先使用完整译文，没有完整译文时使用原文；过滤短问候等内容，从有内容的句子中选择并截取最多 30 个 Unicode 码点，超长时追加省略号。无合适内容时使用日期时间；与现有标题重名时追加序号。这是文字提取，不调用额外模型或网络服务，也不生成内容摘要。

稳定版、iOS 和 Web 保留原有归档界面，以日期时间作为可编辑的默认名称，不提供上述文件夹和改名移动入口。Internal 的操作只影响本渠道数据。

## 错误与降级

- 麦克风或系统音频权限拒绝、音频采集失败、音频中断、ASR 初始化失败和识别进程崩溃会结束当前录音，主页显示可本地化的错误提示。已定稿的行仍保留在主页。
- 单行翻译请求失败只结束该行的等待动画并显示失败标记，不停止转写。macOS 翻译子进程异常退出，或 Web 显式预热本地模型失败，会额外显示引擎级警告并结束所有未完成译文的等待动画。Web 在行翻译期间的模型装载或 Worker 运行失败，以及 iOS Apple Translation 不可用，则表现为行级失败，不额外显示引擎级警告。
- iOS 本地翻译在 iOS 18 以下、不支持的语言对或语言包缺失时不会自动把文本发往云端；该行会失败，需由用户明确改选云端翻译。
- API 翻译需要 Base URL 和模型名；远程端点还需要 API Key。`127.0.0.1`、`localhost` 和 `[::1]` 回环端点允许不填 API Key，并禁止请求重定向。空译文视为失败。请求失败或超时时只影响对应行；应用不会在云端与本地翻译之间自动切换。
- 固定识别语言可规避 `auto` 对短段的部分语种误判；将某个语种专用模型删除后，下次使用它录音时会再次请求下载，不会静默改用其他已下载模型。
